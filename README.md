## 📱 Features

- 🔵 **BLE Device Scanner** — Connect to real BLE health wearables
- 📊 **Real-time Dashboard** — Heart rate, SpO2, HRV, steps, sleep score
- 🤖 **AI Wellness Coach** — Gemini AI analyses your metrics daily
- 📈 **Health History** — 7-day trends with interactive charts
- 🔔 **Smart Alerts** — Notifications for abnormal readings
- 📡 **Offline-first** — Works without internet, syncs when connected
